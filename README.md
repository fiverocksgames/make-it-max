# 🔢 Make It Max

숫자 카드를 배치해 **가장 큰 결과를 만드는 수학 퍼즐 게임**입니다.

계산 자체를 빠르게 푸는 것보다, 주어진 숫자와 연산을 어떻게 조합해야 더 큰 값을 만들 수 있는지 생각하는 플레이에 초점을 둡니다.

[🎮 Make It Max 플레이하기](https://fiverocksgames.github.io/make-it-max/)

## 🎯 How to Play

1. 주어진 숫자 카드를 확인합니다.
2. 숫자와 연산을 조합해 식을 만듭니다.
3. 가능한 선택지 중 더 큰 결과를 만드는 방법을 찾습니다.
4. 여러 경우를 비교하며 자신의 최고 결과에 도전합니다.

## ✨ Project Goals

- 계산과 전략적 선택을 한 흐름으로 연결하기
- 단순 반복보다 여러 경우를 비교하고 판단하게 만들기
- 짧게 플레이해도 규칙과 목표를 바로 이해할 수 있게 하기
- 브라우저에서 가볍게 실행되는 수학 퍼즐 경험 만들기

## 🛠️ Build

이 저장소는 브라우저에서 실행되는 배포 빌드를 담고 있습니다.

현재 공개 파일은 정적 웹 자산으로 구성되어 있으며, 별도의 패키지 설치 없이 웹 서버를 통해 실행할 수 있습니다.

## 🚀 Run Locally

```bash
git clone https://github.com/fiverocksgames/make-it-max.git
cd make-it-max
```

그다음 간단한 로컬 웹 서버로 저장소 루트를 열어 실행하세요.
